# Back Nine

A 3D arcade golf adventure with boss matches and a story, by Tre' Smith (Smith Games).
Built for CSCE 552 (Computer Game Development) at USC.

Dez Carter, a 19-year-old caddie, plays three boss matches to save Pine Hollow, a public course, from the Ashworth Club.

## Requirements
- Godot 4.7 (stable), Forward+ renderer
- Git LFS (for `.glb`, `.png`, `.wav`, `.ogg`)

## Running
1. Open Godot and import `project.godot` from this folder.
2. Press F5 to run.

## Project layout
- `scenes/`: prefabs and scenes (`.tscn`)
- `scripts/`: GDScript
- `assets/`: models, textures, audio
- `docs/`: design documents (GDD)
